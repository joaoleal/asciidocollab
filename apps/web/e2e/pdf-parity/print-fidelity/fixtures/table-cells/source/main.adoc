== An AsciiDoc cell keeps the page's alignment

[cols="1a,1"]
|===
|An AsciiDoc cell holds a whole document of its own, and a left-aligned one is inked at the page's
own alignment rather than flush left, which this theme justifies.

|A plain cell holds a run of text, and a left-aligned one is inked flush left however the page is
set, so its lines end wherever the words do.
|===
