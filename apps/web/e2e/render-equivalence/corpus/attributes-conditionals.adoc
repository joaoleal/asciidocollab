== Conditional Regions

ifdef::project-name[]
This line is included because `project-name` is set.
endif::[]

ifdef::not-set-anywhere[]
This line must never appear in the output.
endif::[]

ifndef::not-set-anywhere[]
This line is included because `not-set-anywhere` is unset.
endif::[]

ifeval::[{release} >= 3.0]
This line is included by an expression evaluated against the attribute's current value.
endif::[]

ifeval::[{release} < 3.0]
This line must never appear in the output.
endif::[]
