Everything here is counted, numbered or labelled by the engine, so a change in any of them shows up
as different output for identical input.

== Footnotes

A sentence with a footnote.footnote:[The first footnote, which the engine numbers.]
A second sentence with another.footnote:[The second footnote — numbering across the two is the point.]
A named footnote, referenced twice.footnote:named[The named footnote's text.]
And the second reference to it.footnote:named[]
